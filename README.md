# **TextureRipper**

A desktop application for extracting, repairing, and generating physically based rendering (PBR) textures from photographs.

TextureRipper allows artists, game developers, and 3D creators to:

Perspective-correct surfaces
Repair texture seams
Preview seamless tiling
Generate Height, Normal, Roughness, and Ambient Occlusion maps

## Features
### Texture Extraction
  - Four-point perspective correction
  - Live texture preview
  - Zoom and pan
  - Edge snapping
  - High-quality export
### Texture Editing
  - Clone Stamp
  - Healing Brush
  - Offset seam editing
  - Undo / Redo
  - Adjustable brush settings
### Texture Processing
  - Lighting normalization
  - Shadow reduction
  - CLAHE contrast enhancement
  - Automatic white balance
  - Saturation adjustment
  - Adjustable seamless blending
### PBR Generation
  - Height Map
  - Normal Map
  - Roughness Map
  - Ambient Occlusion
###Export
  - Custom resolution
  - PNG
  - JPEG
  - BMP
  - Transparency support
